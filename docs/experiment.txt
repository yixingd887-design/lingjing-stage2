灵境视觉智能分析系统——实验记录

一、实验目的

使用同一张公交车图片，分别测试 YOLO 目标检测和视觉大模型分析。

二、YOLO 目标检测结果

1. 检测到 1 辆公交车和 4 个人。
2. 公交车置信度为 94.03%。
3. 检测结果图片保存为 results_bus.jpg。
4. 模型推理耗时为 6.9 毫秒。

三、视觉大模型分析结果

1. 成功返回中文场景描述。
2. 描述了公交车、行人、建筑和街道环境。
3. 部分描述可能存在推断，需要进一步核实。
4. API 响应耗时：17.11 秒（本次测试结果）。

四、初步结论

YOLO 擅长识别目标类别和位置；视觉大模型擅长用自然语言描述图片内容。两者各有优势，可以根据任务需要选择。
